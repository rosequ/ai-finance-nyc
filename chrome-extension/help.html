📋 Terms & Conditions Analyzer - Help Guide

Welcome! This extension helps you analyze terms and conditions on any webpage using AI-powered analysis tools.

🚀 Getting Started

Quick Setup

  1. Ensure the backend API server is running on http://localhost:8000
  2. Look for the 📋 icon in your Chrome toolbar
  3. Click the icon to open the analyzer popup
  4. Click "Analyze Current Page" to get started!

✨ Features

🔍

Page Analysis

Automatically detects if the current page contains terms and conditions with confidence scoring.

🌐

URL Analysis

Analyze any URL for terms and conditions content by entering the URL manually.

🏢

Company Search

Find terms and conditions for any company using intelligent search algorithms.

🎯

Term Highlighting

Highlight relevant terms and phrases directly on the webpage for easy identification.

🎮 How to Use

1. Analyzing the Current Page

  1. Navigate to any webpage
  2. Click the extension icon (📋)
  3. Click "Analyze Current Page"
  4. Review the analysis results and confidence score
  5. Use "Highlight Terms" to mark relevant phrases

2. Analyzing Custom URLs

  1. Open the extension popup
  2. Enter a URL in the "Analyze Custom URL" field
  3. Click the "Analyze" button
  4. Wait for the analysis to complete

3. Finding Company Terms

  1. Open the extension popup
  2. Enter a company name (e.g., "Netflix", "Google")
  3. Click "Find Terms"
  4. The extension will search for and analyze the company's terms

⚙️ Settings

Click the ⚙️ icon in the popup to access settings:

  • API Base URL: Configure your backend server URL (default: http://localhost:8000)
  • Auto-analyze pages: Automatically analyze pages when you visit them
  • Show analysis overlay: Display visual overlays with analysis results

⌨️ Keyboard Shortcuts

Shortcut Action

🔧 Troubleshooting

Common Issues

API Offline Status
If you see "API Offline" in the extension:
  • Make sure the backend server is running: make dev-server
  • Check that the API URL is correct in settings
  • Verify your API keys are configured in the backend

Analysis Not Working

  • Ensure the page has loaded completely
  • Check if the page has meaningful content (not just images/videos)
  • Try refreshing the page and analyzing again
  • Look for error messages in the browser console (F12)

Highlighting Not Visible

  • Ensure analysis found terms indicators
  • Try scrolling down to see highlighted terms
  • Some websites may prevent content modification
  • Refresh the page to remove old highlights

Extension Not Loading

  • Check chrome://extensions/ to ensure it's enabled
  • Try reloading the extension
  • Ensure all extension files are present
  • Check the extension console for errors

🔒 Privacy & Security

  • No Data Collection: The extension doesn't collect or store personal data
  • Local Processing: Analysis happens via your own API server
  • Secure Communication: All API calls use secure protocols
  • Limited Permissions: Only requests necessary Chrome permissions

🎯 Understanding Results

Confidence Scores

  • 90-100%: Very likely to be terms and conditions
  • 70-89%: Probably contains terms content
  • 50-69%: May contain some legal language
  • Below 50%: Unlikely to be terms and conditions

Indicator Types

  • Content Indicators: Terms-related phrases found in page text
  • URL Indicators: Terms-related patterns in the website URL
  • Weight: Importance score for each indicator (higher = more significant)

🛠️ Technical Requirements

Backend Server Required:
This extension requires the AI Finance NYC backend server to be running. The server provides:
